## 📂 项目结构 (Project Structure)

- `/extension`: **Chrome 插件目录**。请在 `chrome://extensions/` 中加载此文件夹。
- `/web`: **看板前端代码**。已通过 GitHub Actions 自动部署。

## 🛠 开发同步 (Development Sync)

1. 在 `chrome://extensions/` 页面加载 `extension/` 文件夹。
2. 复制插件 ID。
3. 在云端看板的右上角输入该 ID，即可实现数据同步。
